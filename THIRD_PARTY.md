# Third-party components and licences

Prize eligibility requires the whole solution to be open source under a permissive
licence (the competition names CC0 / MIT-0), and third-party components need an
explicit open-source licence. Record EVERY dependency, model weight and borrowed
code here BEFORE it enters the submission path. If a licence is unclear, ask the
author for an explicit permissive grant, or do not use it.
